## 1. Модель: кадр = функция времени

Страница не проигрывается сама. `render(t)` выставляет каждый элемент в состояние момента `t`, рендерер вызывает её 60 раз в секунду и снимает скриншот. Отсюда следуют правила:
- **Только явные функции от `t`.** Никаких `setTimeout`, `requestAnimationFrame`, CSS-анимаций и `Math.random()` в render. Случайность — через `rnd()` в `build()`.
- **Любой кадр можно посмотреть отдельно** (`snap.py`), а любой отрезок — перерендерить.
- **Все времена — из `cues.json`.** Заведи в `main.js` объект `C` с началами фраз и ссылайся на него. Текст появляется на слове, а не «примерно тогда».

## 2. Структура проекта

```
proj/
  el/gen1.mp3, gen2.mp3     # озвучка из ElevenLabs
  vo_fit.wav, cues.json     # fit_vo.py
  scenes.html               # разметка сцен (+ свой <svg><defs> с градиентами, если нужны новые)
  main.js                   # const C, IMP; build(); r<Сцена>(t); render(t)
  hud.html                  # прибор, бейдж (необязательно)
  extra.css                 # свои стили (необязательно)
  soundtrack.py             # звук
  index.html                # собирает build_page.py — руками не править
```

Сцена в `scenes.html` — это `<div class="scene" id="ID">`. Внутри: `.bg`, `<svg class="full" id="ID-svg">` и текстовые и плашечные элементы с id вида `ID-что`. В `main.js` на каждую сцену заводится функция `rID(t)`, которая начинается с `if(!scene('ID',t,tin,tout,'whip','zoom'))return;`.

## 3. API lib.js

Шпаргалка по функциям — в шапке `assets/lib.js`. Основное:

| Функция | Что делает |
|---|---|
| `P(t,start,dur,ease)` | Прогресс 0..1. Easing: `Ease.outQuint` (по умолчанию), `outBack` (с перелётом), `outExpo`, `spring`, `inOutCubic`, `inCubic` |
| `bell(t,a,b,c)` | 0→1→0: вспышки, подпрыгивания, пульс |
| `slam(el,t,tin,tout,{st,sc,d})` | Слова `[data-t]` влетают по одному (масштаб `sc` → 1, размытие → 0, шаг `st`). Для хуков `sc` 1,8–2,0 |
| `pop(el,t,tin,tout,{dx,dy,s0,d})` | Плашка, карточка или чип «выпрыгивает». `dx:-40` — выезд слева |
| `H(el,{…})` / `S(g,{…})` | Ручное позиционирование HTML / SVG (x, y, s, r, o, blur) |
| `scene(id,t,tin,tout,inT,outT)` | Показ сцены. Вход: `zoom` / `whip` / `cut` / `up`. Выход: `zoom` / `whip` / `down` / `none` |
| `sc(...)` | То же плюс медленный наезд камеры на 3,5 % — для длинных спокойных сцен |
| `shakeCam(t,IMP)` | Тряска: `IMP=[[t,px],…]`. 6–10 px — акцент, 14–22 px — удар |
| `flashAt(t,[[t,сила],…])` | Белая вспышка: 0,35–0,8 на поворотах |
| `speedo(t,v,vmax,{show,warn})` | Стрелка и число прибора-HUD |
| `badgeAnim(id,t,tin,tout)` | Бейдж рубрики |
| `buildWords()` | Разметка `[data-t]`: `*слово*` → градиент `data-g`, `\|` → перенос. Вызывать в конце `build()` |
| `boardSVG / boardReveal` | Школьная доска с «пишущимися» строками-формулами |
| `cabin(pre)` + `paxSet` | Салон с 30 пассажирами, которым можно «плохеть» |
| `runner(id)` + `runnerAnim` | Персонаж на сверхскорости: шлейф, силуэты-«призраки», линии скорости |

Ключевой параметр — `tout`: момент, когда элемент уходит. Если он не уходит, пиши `1e9`. Не пиши `99`: в видео длиннее 99 с всё исчезнет.

## 4. Переходы, удары, вспышки

- **Переход между сценами** длится 0,24–0,28 с. Чередуй типы: `whip` (свайп) — между частями истории, `zoom` — при «погружении» в деталь, `cut` — на резкий контраст или после стоп-кадра.
- **Тряска** — на каждом слове хука, на цифрах-кульминациях, на «БУМ», на падениях.
- **Вспышка** — 2–4 раза за ролик: на главном повороте, кульминации и смене настроения.
- **Стоп-кадр** перед поворотом: сцена становится серой (`filter: grayscale(1)`) и чуть увеличивается. Звук — скрип пластинки или тишина.
- **Замедленная съёмка:** персонаж движется в 3–5 раз медленнее, линии скорости гаснут, в звуке тянущийся гул и сердце.

## 5. Рецепты сцен

Используй как идеи, а не обязательный набор. Каждая сцена — одна мысль.

| Рецепт | Как сделать |
|---|---|
| Счётчик-масштаб | Большая цифра бежит 0 → N (`fmt`), рядом подпись. Под ней «толпа» или объекты появляются волной |
| Выбор из миллиардов | Крутящийся глобус с точками-людьми, счётчик мелькает, указатель-рулетка замирает на цели |
| Маршрут | Тёмная карта из точек, метки городов, пунктир рисуется маской, по нему летит самолётик |
| Нарастание | Объекты меняют состояние один за другим, всё быстрее (пассажиры зеленеют), фон пульсирует красным |
| Цифра-кульминация | Тёмный фон, огромная цифра «влетает» с масштаба 1,8, мигалки, вспышка |
| Улика крупным планом | Зум на деталь (палец с порезом), заголовок слева, микробы-злодеи вылезают |
| Сравнение | Две полосы-шкалы или две тарелки со знаком ≠; ×N крупно |
| Формула на доске | `boardSVG` + рука героя «пишет», строки проявляются под голос |
| Прибор растёт | `speedo` или термометр с отметкой порога («233 °C — бумага горит») |
| Взрыв / удар | Белое кольцо расширяется, «БУМ!» на весь экран, осколки разлетаются, сигнализации |
| Ловушка | Подготовка (лужи масла, матрасы) → злодей влетает → объяснение закона → столкновение → поролон и звёзды |
| Новость | ТВ-рамка, бегущая строка «СРОЧНО», размытое фото героя |
| «А если бы…» | Та же сцена в тусклом цвете, всё идёт не так, тревога; потом резкий возврат |
| Разрядка | Светлый фон, зелёная галочка, персонажи прыгают, звёзды |
| Возврат к хуку | Фраза хука перечёркивается красной линией → новая фраза зелёным |
| Финал-воронка | «Часть 2 / Следующее видео → в профиле», 3 плитки будущих выпусков, вопрос в комментарии |

## 6. Новый персонаж в стиле

Шаблон (по образцу `victor`, `anna`, `pilot` в lib.js):

```js
function hero(id,skin='#F1C9A5'){return `<g id="${id}"><g id="${id}-in">
  <path d="M-120 330 C-120 170 -72 120 0 120 C72 120 120 170 120 330Z" fill="#2F8F8A"/>   <!-- тело -->
  <rect x="-14" y="96" width="28" height="30" rx="8" fill="${skin}"/>                         <!-- шея -->
  <g id="${id}-hd"><circle cy="20" r="78" fill="${skin}"/>                                   <!-- голова -->
    <ellipse cx="-50" cy="48" rx="14" ry="8" fill="#FF8A8A" opacity=".35"/>…                  <!-- румянец -->
    <g id="${id}-e">…глаза…</g><path id="${id}-m" …/><path id="${id}-mA" … opacity="0"/>      <!-- варианты рта -->
  </g></g></g>`;}
function heroSet(id,{angry=0}={}){ $(id+'-m').setAttribute('opacity',angry?0:1); $(id+'-mA').setAttribute('opacity',angry?1:0); }
```

Как устроен персонаж:
- **Координаты:** начало координат (0, 0) — центр головы, тело уходит вниз до y ≈ 330.
- **Обёртка `-in`:** её масштабируют, чтобы персонаж «дышал» и сжимался.
- **Отдельные id у частей:** глаза, рот, брови, руки — чтобы ими можно было управлять.
- **Градиенты:** новые добавь в `<svg><defs>` в начале `scenes.html`.
- **Масштаб в кадре:** 0,9–1,6.

## 7. Типичные ошибки

- `tout` = 99 в видео длиннее 99 с → текст исчезает. Пиши `1e9`.
- `*на пальце*` с пробелом внутри не раскрасится. Нужно `*на* *пальце*`.
- Бегущая строка или длинный текст вылезает за плашку → оберни в `overflow:hidden`.
- Новая плашка на месте старой без её ухода → наложение. Ставь `tout` старой до `tin` новой.
- Объект «выпадает» из-под рамки кадра в начале сцены (термометр, тарелка) → стартовая позиция за пределами кадра с запасом.
- Текст на светлом фоне в «тёмной» плашке не читается → бейдж и чипы на тёмной подложке.
- Персонаж смотрит или падает не туда (поворот с обратным знаком) → проверь кадрами до и после.
- Сцены не пересекаются по времени: `tout` предыдущей ≈ `tin` следующей (переход 0,24 с выхода перекрывается с 0,28 с входа).
