# Визуальный стиль

Ориентир: презентация Apple, сделанная как мультфильм. Чисто, крупно, жирно, много воздуха, мягкий объём, ничего лишнего в кадре.

## Типографика
- Шрифт **Inter Display**, вес 900 (класс `.h`), межбуквенный интервал −0,045em, межстрочный 1,0–1,1.
- Подписи и подзаголовки: `.sub`, вес 700–800, серый #5B6274 на светлом фоне, #C9D2F2 на тёмном.
- Размеры для 16:9:

| Элемент | Размер |
|---|---|
| Хук | 200–330 px |
| Заголовок сцены | 100–150 px |
| Строка-вывод | 76–110 px |
| Подпись | 36–56 px |
| Чип / пилюля | 30–46 px |

- **Ключевые слова — градиентом.** В `data-t` слово оборачивается в звёздочки `*слово*`, цвет задаётся `data-g`. В одном заголовке 1–3 цветных слова, не больше.
- Палитра градиентов (классы из base.css):
  - `gr` — опасность, запрет (красный → оранжевый).
  - `gp` — эмоция, главное (розовый → оранжевый).
  - `go` — тепло, деньги, огонь, золото.
  - `gb` — вода, холод, наука.
  - `gv` — техника, тайна.
  - `gg` — хорошо, «можно», победа.
  - `gs` — спектр: хук, рубрика, «Часть 2».
- На тёмном фоне текст белый (`.wt`).

## Фоны
- Всегда градиент, а не плоская заливка. Лёгкое радиальное свечение задаёт фокус.
- **Тёмно-синий** (#1B2257 → #04050D) — хук, драма, ночь, тайна, финал.
- **Тёмно-красный** (#3A0E1E → #060306) — опасность, кульминация, злодей.
- **Светлые пастельные** (сиреневый, персиковый, мятный, голубой) — объяснения и разрядка.
- **Тематические** — небо, песок, доска, кухня, улица. Сцена должна сразу говорить, где мы.
- Слой `.bg` шире кадра на 60 px с каждой стороны, чтобы при тряске не было видно краёв.
- **Не используй CSS `filter: blur()` для больших пятен света:** рендер замедляется в разы. Свечение делай через `radial-gradient` (класс `.glow`).

## Плашки и интерфейс
- **`.chip`** — номер или категория над заголовком: кружок-номер с градиентом и короткий текст. На тёмном фоне — `.chip.dark`.
- **`.pill`** — факт или вывод с цветной круглой иконкой (`.pico`). Появляется под голос и остаётся на экране.
- **`.glass`** — стеклянная карточка: цифра-счётчик, сравнение, мини-график, «экран камеры».
- **Прибор-HUD** (hud.html) — спидометр, термометр, процент. Стоит в левом нижнем углу всю «гонку».
- **Бейдж рубрики** — в правом верхнем углу на тёмной подложке, чтобы читался на любом фоне.
- **Внизу экрана** — бегущая строка «СРОЧНО» и подписи-плашки (новости, ТВ).

## Персонажи
- Плоско-объёмные и скруглённые: мягкие градиенты, блик сверху слева, румянец, большие глаза с бликами, толстые контуры не нужны.
- **Живые:** моргают (`blink`), «дышат» (лёгкое масштабирование), покачиваются, реагируют.
- **Эмоции через три детали:** брови (злые — наклон к центру), рот (улыбка, «о», волна-тошнота, оскал), глаза (красные у злодея, крестики при обмороке, сонные веки). Плюс атрибуты: капля пота, звёздочки над головой, «z» сна, «?».
- **Готовые персонажи в lib.js:**
  - Люди: пассажир, пилот, строитель, начальник, полицейский, охранник, учительница, спецназ, супергерой-силуэт.
  - Маскоты: «вкусовой рецептор», капля, звуковая волна, бактерия, ароматик, омлет с лицом.
  - Предметы: самолёт, тарелки, слитки, сумка денег, машины, двигатель, огонь и другие.
  - Полный список — в шапке `assets/lib.js`.
- **Новые персонажи** рисуй в той же технике (см. animation.md): SVG-группа с `-in`-подгруппой для дыхания, отдельные части для мимики, функция `xxxSet()` для эмоций.
- **Без известных персонажей, брендов и логотипов.** Если тема про реальную компанию или фильм, показывай нейтральные предметы и текст.

## Композиция 16:9 (1920×1080)
- Поля 110–140 px. Текстовая колонка слева (x ≈ 110–140), персонаж или объект справа (x ≈ 1300–1500). Либо всё по центру для хука и финала.
- Не больше 3–4 текстовых элементов одновременно. Старое уходит (`tout`) до того, как на его место приходит новое.
- Прибор-HUD — слева внизу (y ≈ 770), бейдж — справа сверху (y ≈ 34). Ничего важного под ними.

## Композиция 9:16 (1080×1920)
- Верхние ~220 px и нижние ~380 px перекрывает интерфейс Reels/Shorts. Текст держи в зоне y ≈ 250–1500, по центру (x = 540).
- Хук не больше 120–140 px и не больше 8–9 символов в строке: больший размер вылезет за кадр. Перенос — через `|`.
- Персонаж под текстом (y ≈ 1100–1500), прибор — внизу по центру или слева.
- `viewBox` у `<svg class="full">` — `0 0 1080 1920`.
