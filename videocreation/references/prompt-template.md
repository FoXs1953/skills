# Шаблон производственного промпта

Используй, когда пользователь просит «промпт», «сценарий», «план видео» или «распиши всё» — для себя, для другой нейросети или для монтажёра. Это самодостаточный документ: по нему видео можно собрать без этого чата. Заполни под тему; разделы, которые не нужны, убери. Длинный документ отдавай в ответе как блок markdown (или Docs, если пользователь хочет хранить/делиться).

```markdown
# ЗАДАЧА
<Одна-две строки: тема, жанр, обещание ролика.> Работай по шагам: сценарий → озвучка → анимация → рендер → проверка.
<Что НЕ делать по теме: соседние темы, которые увели бы в сторону.>

# ТРЕБОВАНИЯ
1. Формат: <16:9 1920×1080 | 9:16 1080×1920>, 60 fps, длительность ≈ <N> с (по истории, не урезать).
2. Язык: <русский>. Закадровый голос ведёт всю историю.
3. Персонажи: оригинальные мультяшные — <кто>. Без известных героев и логотипов.
4. Хук с первой секунды: «<хук>» — каждое слово с ударом.
5. Текст на экране — жирный (Inter Display 900), крупный, ключевые слова градиентом, стиль Apple.
6. Переходы быстрые (0,2–0,3 с); события неторопливые: сцена 5–20 с, паузы голоса ~1 с между блоками.
7. Голос — ElevenLabs, выразительный, с тегами эмоций.
8. Музыка меняет настроение по сюжету + звуковые эффекты на каждом действии.
9. Факты проверены по 2+ источникам; цифры посчитаны.
10. Текст на экране появляется в момент, когда голос его произносит.
11. Финал возвращается к хуку и ведёт в профиль: <часть 2 / следующее видео / вопрос в комментарии>.

# ШАГ 1. ФАКТЫ
Источники: <ссылки>
- <факт — цифра — источник>
- <расчёт: формула → результат>

# ШАГ 2. СЦЕНАРИЙ (≈<слов> слов ≈ <сек> с; числа словами)
«<полный текст голоса по абзацам>»

# ШАГ 3. ОЗВУЧКА
Сайт: https://elevenlabs.io/app/speech-synthesis/text-to-speech
Голос: <Alexandr Vlasov – Vibrant and Energetic | другой>, модель Eleven v4, Stability ≈40 %, Similarity 75 %.
Текст ОДНИМ абзацем с тегами:
<[tag] текст … >
Сгенерировать 2 варианта, выбрать лучший; паузы-акценты: <где>; темп ×<1,0–1,1>.

# ШАГ 4. РАСКАДРОВКА
<время> | <сцена> | <что на экране: фон, персонажи, текст, цифры, переход> | <звук>
… (одна строка на сцену)

# ШАГ 5. ВИЗУАЛЬНЫЙ СТИЛЬ
Шрифт, палитра градиентов, фоны по настроению, плашки (чипы/пилюли/стекло), прибор-HUD, бейдж рубрики, персонажи (плоско-объёмные, моргают, дышат, эмоции через брови/рот/глаза).

# ШАГ 6. ПРАВИЛА АНИМАЦИИ
Слова влетают (масштаб 1,55→1 за 0,3 с, blur→0, шаг 0,07–0,12 с); объекты «попом» (0,55→1 за 0,34 с); переходы зум/свайп/склейка 0,24–0,28 с; тряска 6–18 px на акцентах; белая вспышка на 2–4 больших поворотах; медленный наезд в длинных сценах.

# ШАГ 7. МУЗЫКА И ЗВУКИ
<По блокам: хук — …; завязка — …; нарастание — …; поворот — …; кульминация — …; разрядка — …; финал — …>
Эффекты: whoosh на переходах, удар на заголовках, pop на плашках, тики на счётчиках, предметные звуки.
Сведение: голос главный, музыка на 8–12 дБ тише, итог −14 LUFS.

# ШАГ 8. СБОРКА И РЕНДЕР
HTML/SVG-сцены с render(t) → покадровый рендер 60 fps (Playwright + ffmpeg, H.264 CRF 16) → звук AAC 256k, loudnorm −14 LUFS.

# ШАГ 9. ПРОВЕРКА
Листы кадров каждые ~2 с и на переходах; наложения, обрезки, заглушки; синхронизация текста и голоса; длительность/разрешение/fps; баланс громкости.

# ЧЕГО НЕ ДЕЛАТЬ
- Не уходить от темы. - Не делать медленные «плывущие» переходы и не комкать события.
- Не использовать синтетический монотонный TTS. - Не вставлять в ElevenLabs текст с переносами.
- Не использовать известных персонажей/бренды. - <специфичное для темы>
```
