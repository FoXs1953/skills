# Звук: музыка, эффекты, сведение

Звук синтезируется кодом (`scripts/soundlib.py`): сэмплы и сеть не нужны, а каждый удар можно поставить точно на кадр. Проект — `soundtrack.py` из шаблона.

## Главное правило
Музыка рассказывает ту же историю, что и картинка: у каждого крупного блока своё настроение. Один луп на весь ролик = «уныло и однотонно» — так делать нельзя.

## Настроение → рецепт

| Момент истории | Рецепт soundlib |
|---|---|
| Хук | `hook_hits(s,[t1,t2,t3])` (boom + braam на каждое слово), `lightning()` + `rumble()` для «молнии», `riser` к первой сцене |
| Завязка, загадка | `tension_bed(s,t0,t1)`: низкий гул, тиканье, минорные переборы; `kick_from` добавит пульс |
| Нарастание, «становится хуже» | `heartbeat_run(s,t0,t1,72,180)` + `riser`, заканчивающийся на кульминации |
| Кульминация, цифра, «БУМ» | `impact(s,t)`; при «БУМ» — плюс `burst(...,2500,8000,...)` осколки и `siren` |
| Злодей, ограбление, погоня | `villain_beat(s,t0,t1)`: трэп 140 bpm, 808-бас, ковбелл |
| Размышление, объяснение | `groove(s,…,90,Dm,'marimba',kickg=-17)` или `pad(...)` |
| Лёгкое, «учительница», забавное | `groove(s,…,110,Dmaj,'marimba',clapg=-20)` |
| Крадущееся, ловушка | `groove(s,…,100,Dm,'pizz')` |
| Поворот «но…» | Тишина + `heartbeat` 2–3 раза + низкий гул; `boom` на слове-повороте |
| Замедленная съёмка | `glide_saw(f0,f0*0.75,dur)` (тянущийся гул) + сердце + `riser` к удару |
| Разрядка, финал | `drive(s,t0,t1,120,Dmaj)` (бодрый мажор), `final_chord(s,t)` на последней фразе |
| Тайна, тизер следующей серии | `choir(...)` + редкие `hat` + `boom` на ключевых словах |

## Эффекты (sfx-шина)
- **Каждая смена сцены** — `W1` за 0,05 с до склейки; большие переходы — `W2`.
- **Каждый заголовок или слово хука** — `thump()` (−6…−14 дБ).
- **Появление плашек** — `pop(f)` (−16…−21 дБ); счётчики — серия `tick()` с шагом 0,05 с.
- **Хорошее** — `chime`, `ting`. **Плохое** — `bloop` (тошнота), `slide` вниз (сдулся, разочаровался).
- **Предметные звуки:** `beep` (тревога, телевизор), `shaker` (соль), `crunch` (укус), `crackle` (огонь), `burst` (стекло, мел, шаги), `siren`.
- Подбирай звуки под то, что видно в кадре: каждое заметное действие на экране должно что-то звучать.

## Баланс и громкость
- Голос — главный. `Session` слегка компрессирует голос и приглушает музыку под ним (`duck=.6`).
- Цель: музыка на **8–12 дБ тише голоса** в каждой части, эффекты примерно на уровне музыки. `s.stems([...диапазоны сцен...])` печатает RMS и помечает «too loud / too quiet».
- Тихие секции поднимай через `s.section_gain([(t0,t1,+дБ),...])`, слишком громкие опускай. Удары (`impact`) могут быть громче — это короткие пики.
- Итоговая громкость −14 LUFS / −1,2 dBTP ставится в `finalize.py`.
- Ты не слышишь результат. Проверяй цифрами и честно предупреждай пользователя, что громкость и ударения нужно проверить на слух.
