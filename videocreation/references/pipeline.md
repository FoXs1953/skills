# Конвейер: команды, время, проверка, ловушки

## Команды по порядку
```bash
SKILL=<путь к videocreation>; P=<scratchpad>/<проект>; mkdir -p $P/el && cp $SKILL/assets/template/* $P/
python3 $SKILL/scripts/segment_vo.py $P/el/gen1.mp3 $P/el/gen2.mp3
python3 $SKILL/scripts/fit_vo.py $P/el/gen1.mp3 --keep '{"0":0.4}' --max-gap 0.22 --tempo 1.0 --offset 0.1 --out-dir $P
# … пишем scenes.html / main.js по cues …
python3 $SKILL/scripts/build_page.py $P --title "Название" [--size 1080x1920]
python3 $SKILL/scripts/snap.py $P/index.html 0.5 2 4 … --out $P/snaps --sheet $P/sheet.png --cols 3 [--size 1080x1920]
VIDEOCREATION=$SKILL python3 $P/soundtrack.py
python3 $SKILL/scripts/render.py $P/index.html --dur 60 --jobs 2 --out $P/video.mp4 [--size 1080x1920]   # в фоне
python3 $SKILL/scripts/finalize.py --video $P/video.mp4 --audio $P/mix.wav --dur 60 --out "$P/<Название>.mp4" --sheet $P/check.png --extra <времена переходов>
```

## Бюджет времени
| Этап | Сколько |
|---|---|
| Факты и сценарий | 5–10 мин |
| ElevenLabs | 3–5 мин работы + ожидание пользователя (вход) |
| Сцены и main.js | Самая большая часть: 10–20 мин, 2–3 итерации листов `snap.py` |
| Звук | 3–5 мин (скрипт синтеза 10–60 с) |
| Рендер | ≈0,15–0,2 с на кадр на процесс; `--jobs 2`: минута видео ≈ 5 мин, две минуты ≈ 11 мин |

Рендер запускай в фоне. Пока он идёт, делай звук, а пользователю напиши одну строку о том, что происходит.

## Проверка (до отправки)
1. **`snap.py` перед рендером.** Листы кадров каждые 1,5–3 с плюс отдельные кадры на переходах (tin и tout каждой сцены ± 0,1 с). Смотри на наложения, вылеты за край, заглушки, пустые кадры, читаемость на фоне, совпадение текста с репликой.
2. **JS-ошибки** выводятся в `snap.py` и `render.py`. Ошибка = чёрный или застывший кадр: исправь до рендера.
3. **`finalize.py`** печатает длительность, разрешение и fps и делает `check.png`. Посмотри его целиком.
4. **Звук:** таблица `stems` без пометок «too loud / too quiet».
5. Если что-то испорчено в отрезке: `render.py --from A --to B --out seg.mp4` (A и B кратны 1/60), потом склей `ffmpeg concat` из кусков, перекодированных одинаково. Не склеивай через `filter_complex concat` 60 fps 1080p: падает по памяти.

## Известные ловушки (на них уже наступали)
- **Огромные пятна света через `filter: blur(130px)`** — один кадр 0,4 с, рендер 25 мин. Используй `radial-gradient`.
- **`tout=99`** в ролике длиннее 99 с — исчезает весь текст после 99-й секунды. Используй `1e9`.
- **`*два слова*`** не раскрашивается. Нужно `*два* *слова*`.
- **Перенос строк в ElevenLabs** — озвучена только первая строка.
- **Кнопка в ElevenLabs по координатам** промахивается после смены размера окна. Сделай свежий скриншот или используй `find` и `ref`.
- **Временный файл в «Загрузках»** переименовывается на лету. Перечитай папку.
- **`pip`/`npm` за прокси часто недоступны.** Всё нужное (Playwright, Chromium, ffmpeg, numpy, scipy, шрифт Inter) уже есть в среде. Не завязывайся на новые пакеты.
- **`print | head`** в скриптах даёт BrokenPipe — это безвредно.
- **Плашка «бейдж» прозрачная** на светлом фоне не видна. Держи тёмную подложку.

## Сдача
- `SendUserFile` с MP4 (`display: "render"`) и подписью в одну строку: длительность, формат, голос.
- В ответе:
  - Что внутри — коротко по сценам.
  - Что учтено из пожеланий.
  - Что проверить на слух.
  - Если обещано продолжение — напоминание.
- Повтор шагов и технические детали — только если пользователь спросит.
